# 通用日用模板

这是一套独立于当前默认方案的通用样例模板，适合拿来演示本地提醒、循环计时和手动快捷键记录等基础能力。

## 设计目标

- 偏日常使用场景，而不是专项场景
- 默认关闭 OCR 自动识别与目标事件识别
- 保留分组循环、全局事件、主技能提醒、扩展技能提醒这些通用能力
- 配套资源使用中性命名，便于后续二次定制

## 目录内容

- `config.json`
  通用日用场景样例配置
- `assets/`
  与该样例配置配套的模板资源副本

## 样例场景

这份模板默认模拟的是一个 25 分钟专注时段中的基础提醒：

- `20:00` 喝水提醒
- `10:00` 起身活动
- `F6` 手动记录“喝水提醒”
- `F7` 手动记录“眼部休息”
- `Alt` 手动记录“短休息”
- `Num1 / Num2 / Num3` 用于三组轮换提示

## 使用建议

- 如需试用这套模板，请将其中的 `config.json` 和 `assets` 单独拷贝到测试环境中使用。
- 这套模板不会改动当前项目根目录下的默认 `config.json` 或 `assets`。
- 如果你要继续做更强的通用化，可优先修改事件名称、快捷键、音频内容和循环分组名称。
