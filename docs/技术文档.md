# LocalInfoReminder 技术文档

**版本**: 1.0.0
**生成日期**: 2025-12-18

## 1. 项目概述 (Overview)

**LocalInfoReminder** 是一款用于本地屏幕信息识别、提醒与可视化展示的通用桌面工具，主要功能包括分组循环提醒、屏幕信息实时识别（OCR）、条目倒计时以及目标事件状态通知。

项目基于 **Python 3.12** 和 **PyQt6** 开发，采用模块化架构，核心特性包括：
- **独立的逻辑引擎**：基于时间轴的可配置条目调度。
- **视觉识别子系统**：集成 `RapidOCR` 和 `OpenCV`，实现毫秒级的时间同步与状态检测。
- **高级输入管理**：支持键盘/鼠标钩子、双击判定、长按判定及独立的“输入模式”切换。
- **透明悬浮层 (Overlay)**：用于屏幕上方的 UI 可视化展示。

## 3. 核心模块详解 (Core Modules)

### 3.1 逻辑引擎 (LogicEngine)
`src/core/logic_engine.py`
项目的“大脑”。负责协调输入信号、屏幕事件和界面更新。
- **职责**:
    - 维护全局时间（`Server Time` vs `Local Time`）。
    - 实例化并管理所有的 `GroupController`（各分组）。
    - 处理 `ScreenMonitor` 发来的 OCR 信号（时间同步、目标事件出现）。
    - 发送最终的 UI 状态数据给 `OverlayWindow`。

### 3.2 调度器 (Scheduler)
`src/core/scheduler.py`
实现了循环提醒的核心排序算法。
- **核心概念**:
    - **Wait Queue**: 正在等待倒计时结束的条目。
    - **Ready Queue**: 条目倒计时结束后的待处理队列。
    - **Active Duration**: 条目处于活动状态的持续时间。
- **算法**:
    优先级排序：`Buffing > Ready (按 ID 顺序) > Cooling Down`。

### 3.3 视觉子系统 (Vision Subsystem)
`src/core/vision/`
基于 `mss` (截屏) + `RapidOCR` (文字识别) + `OpenCV` (颜色分析)。
- **TimeRecognizer**: 识别屏幕顶部倒计时，误差控制在 500ms 内。
- **TargetEventDetector**:
    - **Spawn Check**: 每 60 秒检查一次目标事件是否出现。
    - **Kill Check**: 在目标事件时段内，通过红蓝像素比例判断事件归属，并通过 OCR 关键词确认。
- **SkillDetector**: 实时监控配置区域，通过颜色阈值触发（低 CPU 占用），仅在颜色匹配时进行 OCR 二次确认。

### 3.4 输入管理 (Input Subsystem)
`src/core/input/`
为解决复杂的按键需求（双击、长按、组合键）而设计的独立模块。
- **InputListener**: 封装 `keyboard` 和 `mouse` 库，提供统一的事件流。
- **KeyMapper**: 将配置文件（JSON）中的按键定义解析为内存中的查找表。支持一对多绑定。
- **InputState**: 纯逻辑类。记录每个键的 `press_time`，利用时间差判定 `Single Tap` vs `Double Tap` vs `Long Press`。

### 3.5 界面系统 (UI System)
基于 PyQt6。
- **Launcher**: 现代化风格的启动器，支持配置管理和运行入口。
- **Overlay**:
    - **点击穿透 (Passthrough)**: 通过 Windows API (`GetWindowLong`, `SetWindowLong`) 动态切换窗口属性，实现窗口交互与 UI 操作的无缝切换。
    - **透明背景**: 使用 `rgba(0,0,0, alpha)` 实现半透明效果。

## 4. 关键工作流 (Key Workflows)

### 4.1 主循环 (Main Loop)
程序由 Qt 的事件循环驱动，但核心业务逻辑由 `LogicEngine` 的 `QTimer` 驱动（Tick Rate: 100ms）。
1.  **Tick**: `LogicEngine._process_tick()` 被调用。
2.  **Time Sync**: 检查是否需要根据 OCR 结果校准内部时钟。
3.  **Update Groups**: 遍历所有 `GroupController`，调用 `update()`。
    - Scheduler 计算当前应该播放什么语音、显示什么状态。
4.  **Emit UI**: 收集所有组的状态，打包成字典，通过 Signal 发送给 `Overlay` 更新界面。

### 4.2 输入处理 (Input Flow)
1.  **硬件事件**: 用户按下 `Num 1`。
2.  **InputListener**: 捕获事件，标准化为字符串 `"num_1"`。
3.  **InputManager**: 收到信号，加锁，转发给 `InputState`。
4.  **InputState**:
    - 记录按下时间。
    - 查询 `KeyMapper` 找到对应的功能（例如：触发分组 A）。
    - 暂存状态。
5.  **释放事件**: 用户松开按键。
    - `InputState` 计算按压时长。
    - 若时长 < 0.3s，且无待定双击逻辑 -> 确认为 `Single Tap`。
    - 若配置了双击 -> 启动 0.35s 延时计时器。
6.  **Action Dispatch**: `InputManager` 将最终决策（`GESTURE: single_tap`）通过信号发送给 `LogicEngine` 执行。

## 5. 配置文件 (Configuration)

`config.json` 是系统的核心数据源。

```json
{
  "classes_template": [
    {
      "id": "1",
      "name": "Group A",
      "default_hotkey": "1",      // 基础热键
      "skip_cd_hotkey": "2",      // 跳过并计入 CD 热键
      "independent_hotkeys": ["3", "4"], // 独立模式专用键
      "skill_cooldown": 18,       // 条目倒计时
      "buff_duration": 12,        // 活动持续时间
      "pre_cast_delay": 0.5       // 前摇补偿
    }
  ],
  "primary_entries": [ ... ],     // 主要条目监控配置
  "overlay_bg_alpha": 220         // UI 透明度
}
```

## 6. 开发与构建 (Development & Build)

### 环境要求
- Windows 10/11
- Python 3.12
- 依赖库: `PyQt6`, `mss`, `rapidocr_onnxruntime`, `opencv-python`, `keyboard`, `mouse`, `numpy`.

### 构建 (PyInstaller)
构建生产环境 EXE 的命令：

```powershell
.\venv\Scripts\python.exe -m PyInstaller packaging\specs\LocalInfoReminder.spec --noconfirm --clean
```

### 调试建议
- **OCR 调试**: 使用 `Ctrl+I`, `Ctrl+O`, `Ctrl+U` 可分别截取当前屏幕的主要条目区、目标事件区、时间区并保存到 `debug_imgs/` 目录，用于分析识别失败原因。
- **日志**: 查看 `logs/runtime/debug.log` 获取详细运行堆栈。
