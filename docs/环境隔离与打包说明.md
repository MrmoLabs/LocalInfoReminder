# 环境隔离与打包说明

## 背景

部分 Windows 开发环境可能设置了指向全局 `site-packages` 的用户级 `PYTHONPATH`。
这会使 Python 在进入项目 `venv` 后，仍然优先从项目外部加载依赖。

为了避免影响其他项目，本项目改为在启动前仅清空当前会话的 `PYTHONPATH`。

## 推荐用法

### 1. 进入项目本地虚拟环境

```powershell
.\use_venv.ps1
```

这个脚本会：

- 清空当前会话的 `PYTHONPATH`
- 激活 `venv`
- 确认当前 Python 来自项目 `venv`

### 2. 源码运行

```powershell
python src/main.py
```

如果不想先执行 `use_venv.ps1`，请至少使用：

```powershell
$env:PYTHONPATH=""
.\venv\Scripts\python.exe src/main.py
```

### 3. 运行测试

```powershell
.\run_tests.bat
```

`run_tests.bat` 已内置 `PYTHONPATH` 清理逻辑，会优先使用项目 `venv`。

### 4. PyInstaller 打包

```powershell
.\venv\Scripts\python.exe -m PyInstaller packaging\specs\LocalInfoReminder.spec --noconfirm --clean
```

源码运行、测试和打包统一使用 Python 3.12 的项目 `venv`。项目只保留普通 PyInstaller spec，不执行源码混淆。
