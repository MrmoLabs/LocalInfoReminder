# 本地信息提醒工具使用手册

## 1. 使用前说明

- 本工具主要以离线方式运行，识别、提醒与本地状态处理均在本机完成。
- 软件依赖管理员权限运行，否则全局热键、键鼠监听或部分本地状态写入可能异常。
- 使用前请自行确认目标平台的用户协议、服务规则及其他适用要求。
- 运行日志默认写入 `logs/`，运行期状态文件默认写入 `state/`。

## 3. 悬浮窗操作

软件启动后，屏幕上方会显示状态悬浮窗。

- 按 `Ctrl + M` 可切换悬浮窗锁定与解锁状态。
- 解锁后可拖动位置，也可按当前界面能力进行缩放调整。
- 如需修改显示效果，可在“配置管理”中调整透明度、字号、窗口尺寸等参数。

## 4. ROI 编辑器与 OCR / 颜色调试

时间同步、主条目和目标事件都保留原来的模块入口按钮，点击后会进入统一的 ROI 编辑器。

ROI 编辑器当前包含两个分页：

- `区域概览`：查看 ROI 位置、缩略预览、比例坐标和像素坐标
- `联动调试`：同屏查看颜色检测结果、命中遮罩和 OCR 识别状态

常用操作包括：

- `重新截图` 更新当前背景
- `Ctrl + 滚轮` 围绕鼠标位置缩放截图
- 中键拖动或“空格 + 左键”平移画布
- 直接编辑 ROI 的比例或像素数值
- `截图取色` 并拖动预览颜色效果
- 实时查看容差切片预览、命中遮罩预览、命中像素数和 OCR 状态
- `Ctrl + T` 手动触发 OCR 测试

所有 ROI 均使用比例保存，因此切换分辨率后不需要重新按像素填写。

## 5. 目标事件提醒

目标事件相关提示主要用于显示识别到的事件状态与倒计时信息。

- `target_event_notification` ROI 用于播报文本识别
- `target_event_result` ROI 用于结果文本识别
- 播报与结果识别都会结合 OCR 关键字和颜色判定
- 颜色判定现在基于采样颜色、容差和命中比例三个参数

## 6. 分组循环与主条目提醒

本功能用于管理分组循环、主条目与扩展条目的计时提醒。

- 分组循环可用于顺序轮转提醒
- 主条目支持触发记录、冷却倒计时、截止阈值闪烁与截止音频提醒
- 扩展条目支持触发记录，并可在接近结束时通过 `flash_threshold` 进行闪烁提示

## 7. 按键与配置管理

如需修改快捷键或其他配置：

1. 打开“配置管理”。
2. 进入“分组配置”、“主条目”、“扩展条目”或“目标事件设置”。
3. 点击对应输入框后，直接按下目标按键或填写参数。
4. 点击“保存并应用”使配置生效。

建议优先检查以下配置项：

- 快捷键是否与本机其他软件冲突
- 音频文件路径是否有效
- ROI 区域、OCR 关键字、颜色采样和命中比例是否与当前界面匹配
- 透明度、字号和窗口尺寸是否适合当前分辨率

## 8. 音频与资源自定义

用户可替换软件目录 `assets` 文件夹下的资源进行个性化定制。

- 产品图标文件为 `assets/LocalInfoReminder.ico`
- 语音播报资源通常位于 `assets` 子目录下的 `.mp3` 文件
- 替换图标或音频资源后，建议重启软件使更改生效

## 9. 常见问题

- 提醒不准确或没有识别到
  请优先检查 ROI 区域、OCR 关键字、颜色采样、容差、命中比例和当前显示内容是否一致

- 修改配置后没有生效
  请确认已点击“保存并应用”，必要时重启软件

- 想查看程序日志或本地状态
  运行日志通常位于 `logs/runtime/debug.log`，本地状态文件位于 `state/`
